### 2.2 Flight Centre — third-party accommodation booking system

- **Date / status:** Company ASX statement dated 26 Nov 2026; investigation ongoing.
- **Impact:** Flight Centre Travel Group says a significant number of customer records in a third-party accommodation booking system may have been accessed; the number extracted is unknown. - **CVE / severity / KEV:** None disclosed; no CVE or KEV status identified.

Affected partners should inventory integrations and rotate credentials where the provider directs; do not assume every Flight Centre supplier is affected.
- **KQL:** None — the third-party platform and schema are unnamed; a generic tenant query would not detect provider-side extraction.
- **Confidence / attribution:** High that Flight Centre made the disclosure; scope and extracted-record count remain unknown. No actor attribution.

<details>
<summary>Q1 — Vates Xen Orchestra: vendor IOC IP/domain hunt</summary>

**Purpose:** Find network telemetry matching Vates' published campaign IPs or Tor onion hostname. This is a narrow IOC hunt, not proof that an installation is clean when no match is found.

**Data source/table:** Microsoft Sentinel `CommonSecurityLog` from firewall, proxy or network-security connectors.

**Schema assumptions:** Standard `TimeGenerated`, `SourceIP`, `DestinationIP` and `Message` fields are populated. The query does not assume that every device logs HTTP cookies or DNS hostnames.

**Maturity:** Draft — not tenant-schema-checked, Kusto-parser-validated, lab-tested or production-approved.

**Tuning notes:** Validate connector coverage and NAT/proxy normalization. Add the complete current IOC list from Vates' advisory to your threat-intelligence watchlist. Include DNS/proxy logs separately if the onion hostname is observable. A match requires triage; absence of a match is not evidence of no compromise.

```kql
let IOC_IPs = dynamic([
    "91.211.251.112",
    "193.148.56.72",
    "37.221.208.216",
    "45.66.35.11",
    "64.65.0.120",
    "64.65.62.160",
    "89.47.51.90",
    "92.60.37.247"
]);
let IOC_Domain = "ustar3rqxgnskzgnwkgpofgtvxevm6cx3lxdbwt4mndtveqyaohid.onion";
CommonSecurityLog
| where TimeGenerated >= ago(7d)
| where SourceIP in (IOC_IPs)
    or DestinationIP in (IOC_IPs)
    or Message has IOC_Domain
| project TimeGenerated, DeviceVendor, DeviceProduct,
          SourceIP, SourcePort, DestinationIP, DestinationPort,
          Activity, Message
| order by TimeGenerated desc
```

</details>

<summary>Q2 — MONAI Label: datastore upload path-traversal hunt</summary>

**Purpose:** Identify PUT requests to MONAI Label datastore endpoints where the logged URI contains common literal or URL-encoded traversal sequences. This is a request hunt, not proof that a file write succeeded.

**Data source/table:** Microsoft Sentinel `AzureDiagnostics`, Application Gateway access logs.

**Schema assumptions:** `Category`, `httpMethod_s`, `requestUri_s`, `clientIP_s`, `httpStatus_d`, `host_s` and `transactionId_g` are present. The URI must include the query string for the `image` parameter to be visible.

**Maturity:** Draft — schema assumptions are illustrative; not tenant-schema-checked, Kusto-parser-validated, lab-tested or production-approved.

**Tuning notes:** Confirm whether the deployment uses Application Gateway, Front Door, NGINX, ingress or another reverse proxy. Normalize URL encoding at the edge where possible. Baseline legitimate datastore uploads; correlate suspicious requests with application/file-integrity and process telemetry. Include blocked and successful HTTP statuses.

```kql
AzureDiagnostics
| where TimeGenerated >= ago(24h)
| where Category == "ApplicationGatewayAccessLog"
| where httpMethod_s =~ "PUT"
| where requestUri_s contains "/datastore/image"
    or requestUri_s contains "/datastore/label"
| where requestUri_s contains "../"
    or requestUri_s matches regex @"(?i)%2e%2e|%252e%252e"
| project TimeGenerated, host_s, clientIP_s, httpStatus_d,
          httpMethod_s, requestUri_s, transactionId_g
| order by TimeGenerated desc
```

</details>

<details>
<summary>Q3 — ARTEX: machine-speed web request bursts and tool user agents</summary>

**Purpose:** Find high-rate, high-path-diversity or high-client-error request bursts and known ARTEX/NORMA user-agent strings across IIS, App Service and Application Gateway logs.

**Data source/table:** Microsoft Sentinel W3CIISLog, AppServiceHTTPLogs and AGWAccessLogs.

**Schema assumptions:** Field names follow Microsoft's published query assumptions: cIP/csUriStem/scStatus/csUserAgent/Computer; CIp/CsUriStem/ScStatus/UserAgent/CsHost; ClientIp/RequestUri/HttpStatus/UserAgent/Host. Deploy only for tables that exist in the workspace.

**Maturity:** Draft — not tenant-schema-checked, Kusto-parser-validated, lab-tested or production-approved. No query has been run in a customer tenant.

**Tuning notes:** Baseline per application and source IP; user-agent strings are trivial to spoof, so combine with request rate, path diversity, client errors, process execution and identity changes. Thresholds are starting points, not universal alert values.

```kql
let Window = 10m;
union isfuzzy=true
(
    W3CIISLog
    | project TimeGenerated, LogSource = "IIS", ClientIP = cIP,
              Path = csUriStem, Status = tostring(scStatus),
              UserAgent = csUserAgent, Target = Computer
),
(
    AppServiceHTTPLogs
    | project TimeGenerated, LogSource = "AppService", ClientIP = CIp,
              Path = CsUriStem, Status = tostring(ScStatus),
              UserAgent = UserAgent, Target = CsHost
),
(
    AGWAccessLogs
    | project TimeGenerated, LogSource = "AppGateway", ClientIP = ClientIp,
              Path = RequestUri, Status = tostring(HttpStatus),
              UserAgent = UserAgent, Target = Host
)
| where isnotempty(ClientIP)
| summarize Requests = count(),
            DistinctPaths = dcount(Path),
            ClientErrors = countif(toint(Status) between (400 .. 499)),
            UserAgents = make_set(UserAgent, 5),
            Targets = make_set(Target, 5)
    by ClientIP, bin(TimeGenerated, Window)
```

**Maturity:** Draft — not tenant-schema-checked, Kusto-parser-validated, lab-tested or production-approved. No query has been run in a customer tenant.

```kql
let Lookback = 30d;
let FileHits =
    DeviceFileEvents
    | where Timestamp >= ago(Lookback)
    | where (FileName =~ "OskSupport.dll"
             and FolderPath has @"\AppData\Local\osk")
        or (FileName =~ "Launcher.exe"
            and FolderPath has @"\Temp")
```
