## 2) TODAY'S THREATS

### 2.1 Keycloak policy-selected OTP flow can accept a lower-assurance password SSO session

- **Date/status:** The CVE feed entry surfaced 25 November 2026 at 01:42 UTC (07:12 IST), while the CVE record's public-date field shows 23 November 2026. Treat this as a newly indexed record, not a confirmed 25 November disclosure.
- **Impact:** A client policy expecting a high-assurance OTP flow may accept an existing password-only SSO session if the request does not explicitly demand the assurance level. An attacker who already has a user's password or session could receive a token claiming higher assurance than was completed.
- **Affected products/regions:** Red Hat Build of Keycloak and Red Hat Single Sign-On 7; the CNA record does not yet specify the exact affected release range or fixed package build.
- **CVE/severity/KEV:** CVE-2026-135768; CVSS 3.1 6.8 Medium; not in CISA KEV; no vendor-confirmed exploitation or public PoC identified.
- **Detect:** Compare authentication flow and token assurance claims with the actual OTP event; look for token issuance after password-only SSO where policy expected OTP.
- **Fix/contain:** Red Hat's VEX says no mitigation currently meets its supported criteria. Track the vendor erratum. Temporary risk reduction: review clients to ensure they explicitly request the required assurance level, invalidate sessions after policy changes, and require fresh MFA for sensitive operations. These are compensating controls, not a vendor fix.
- **KQL:** Q7 — Keycloak OTP assurance-flow log review.
- **Confidence/attribution:** High confidence in the CNA description; no actor attribution.
- **Sources:** [Red Hat CVE record](https://access.redhat.com/security/cve/CVE-2026-135768) · [CVE record mirror with Red Hat VEX details](https://cve.circl.lu/vuln/CVE-2026-135768).

### 2.2 JaguarJack catch-admin mass-assignment issues

- **Date/status:** CVE-2026-136444 and CVE-2026-136445 published 25 November 2026; newly disclosed. Related CVE-2026-136446 also appeared in current CVE feeds, but its patch relationship needs separate vendor confirmation.
- **Impact:** Dynamically determined object attributes in user/role management actions may allow a low-privileged authenticated user to alter fields they should not control.
- **Affected products/regions:** JaguarJack catch-admin 5.4.0 and 5.4.1 per the CVE records.
- **CVE/severity/KEV:** CVE-2026-136444 and CVE-2026-136445; CVSS v4 5.3 Medium. Not in KEV. CVE records contain an uncorroborated “exploit may be used” statement; no independently validated public PoC or vendor-confirmed exploitation was found.
- **Detect:** Review user/role create and update audit events for changes to privilege, role, permission, tenant or ownership attributes not present in the approved request.
- **Fix/contain:** The records reference patch commit `3ae60d57ea6840bb33456596ad799b0a39ca94a2`; verify the project release containing it before marking fixed. Restrict user/role administration to trusted administrators and review recent role changes.
- **KQL:** No universal query; application audit schema is project-specific.
- **Confidence/attribution:** Medium; CNA is VulDB and NVD status is deferred. Do not treat the “exploit may be used” phrase as confirmed exploitation.

#### 2.3.1 Amazon ECS MCP Server sensitive-data redaction bypass

- **Date/status:** AWS bulletin 2026-200-AWS published 24 November 11:00 AM PST (25 November 00:30 IST).
- **Impact:** With the sensitive-data setting at its default, the troubleshooting tool could return task-definition environment-variable values and secret references without the intended redaction. Prompt injection may influence an agent to reveal those values.
- **Affected products/regions:** Open-source `awslabs.ecs-mcp-server` before 0.1.36.
- **CVE/severity/KEV:** CVE-2026-135614; AWS rates it Important; no KEV listing or confirmed exploitation identified.
- **Detect:** AWS CloudTrail ECS API reads such as DescribeTaskDefinition, ListTaskDefinitions and DescribeTasks; correlate caller, role/session, source IP, user agent and agent conversation context.
- **Fix/contain:** Upgrade to 0.1.36 or later; patch forks/derivatives; remove plaintext secrets from task environment variables and rotate any that may have been exposed.
- **KQL:** Q2 — ECS task-definition access review.
- **Confidence/attribution:** High confidence (AWS bulletin); no actor attribution.
- **Sources:** [AWS Security Bulletin 2026-200-AWS](https://aws.amazon.com/security/security-bulletins/2026-200-aws/).

#### 2.4.3 Idunno.AntiCsrf unkeyed deserialization RCE

- **Date/status:** CISA KEV addition 24 November; federal remediation due 27 November. Mandiant's disclosure reports active exploitation in the wild.
- **Impact:** The legacy ASP.NET HTTP module deserializes untrusted CSRF form-token data before validating it. A remote POST can execute code in the IIS worker-process context and compromise the WebForms application server.
- **Affected products/regions:** Applications that load Idunno.AntiCsrf 0.9.1.0 / 0.9.1 Beta; the project is unmaintained and has no fixed release.

<summary>Q1 — VMware vCenter / ESXi authentication and admin-session triage</summary>
