- Technology background: **What is it?** PolinRider is a software-supply-chain malware campaign that plants loader code in public GitHub repositories. **What does it do?** A Python loader retrieves JavaScript from Ethereum transaction calldata and launches a follow-on stage through Node.js.
- Technical details:
  - SafeDep found this Python loader in 375 repositories across 260 GitHub accounts as of 24 November 2026; this is distinct from broader campaign estimates above 7,600 repositories.

## Analyst notes and limitations

- Feed success confirms retrieval, not that every feed record is a distinct, relevant threat.
- CISA KEV dateAdded is date-only; the 24-hour filter is therefore date-precision, not timestamp-precision.
- A vendor-published fix does not mean it is installed in any environment. Validate deployed package/build versions.
- A vendor's statement of containment is attributed to the vendor and is not independent validation.
- The collector stores normalized records and source URLs, not a complete copy of every source article.
- Quarantined records remain available for later review; roundups must be decomposed into individual events before publication.
